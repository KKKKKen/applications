# インターバルタイマー

タバタ／ラウンド式のインターバルタイマー。ブラウザで開くだけで使え、ホーム画面に追加すると全画面のアプリとして動きます。無料・広告なし・オフライン対応。

- 設定項目: 準備・ワークアウト・休憩・ラウンド数・サイクル数・サイクルの休憩・クールダウン
- 残り 3 秒と切り替わりで音が鳴り、実行中は画面が消えません
- 設定と記録は端末に保存されます

## 使い方（iPhone）

Safari で開き、共有ボタン → 「ホーム画面に追加」。

## 記録を Google スプレッドシートに残す

タイマーが完了するたびに、日付・開始・終了・種類・合計時間が 1 行ずつスプレッドシートに書き足されます。
手順は [apps_script/Code.gs](apps_script/Code.gs) の冒頭に書いてあります。出てきたウェブアプリの URL を、タイマーの設定画面「記録の送り先」に貼るだけです。URL は端末の中にだけ保存され、このリポジトリには載りません。

電波がない時は端末に溜め、次に開いた時や繋がった時にまとめて送ります。同じ記録は ID で見分けるので、再送しても行は増えません。

## 更新のしかた

`index.html` を書き換えて push するだけです。`sw.js` の `CACHE` の番号を上げると、開いている端末が次回起動時に新版へ切り替わります。
